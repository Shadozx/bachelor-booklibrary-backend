# Bachelor BookLibrary — Backend

**Bachelor BookLibrary Backend** — серверна частина вебзастосунку для онлайн-бібліотеки, створена у межах бакалаврського проєкту. Реалізована на **Java 17** з використанням **Spring Boot**, система забезпечує функціональність REST API для роботи з книгами, розділами, оцінками, коментарями, закладками, користувачами та ролями.

Проєкт підтримує авторизацію на основі JWT, рольову модель доступу, адміністративну панель, обробку HTML-даних із зовнішніх джерел (через `jsoup`) для заповнення БД книгами та валідацію введення.

---

## Технології та залежності

- **Java 17**
- **Spring Boot**:
  - `spring-boot-starter-web` — обробка HTTP-запитів  
  - `spring-boot-starter-data-jpa` — доступ до БД через JPA  
  - `spring-boot-starter-validation` — валідація DTO  
  - `spring-boot-starter-security` — авторизація та аутентифікація  
  - `spring-boot-starter-thymeleaf` — шаблонізатор для веб-інтерфейсу
- **PostgreSQL** — основна база даних
- **H2** — база для тестування
- **Lombok** — скорочення шаблонного коду (гетери, сетери, конструктори)
- **JWT (JJWT)** — токени для безпечної аутентифікації
- **MapStruct** — мапінг між DTO та Entity
- **Jsoup** — парсинг HTML (для імпорту книг)
- **Jackson** — JSON-серіалізація
- **Apache HttpClient 5** — для запитів до сторонніх API
- **Spring Boot Test** — модульне тестування

---

## Призначення

Бекенд реалізує основну бізнес-логіку платформи:

- CRUD-операції з книгами, розділами, оцінками (1–5), коментарів, закладок
- Керування користувачами та ролями
- Аутентифікація з використанням JWT
- Парсинг HTML-джерел книг через `Jsoup`
- REST API для взаємодії з frontend-частиною  
  (див. [frontend репозиторій](https://github.com/Shadozx/bachelor-booklibrary-frontend))

## Рольова модель доступу

| Роль                   | Можливості                                                                  |
|------------------------|-----------------------------------------------------------------------------|
| **Користувач**          | Перегляд книг, коментування, оцінювання, додавання до закладок             |
| **Адміністратор**       | Повне керування контентом (книги, розділи, коментарі)          |
| **Суперадміністратор**  | Додатково керування ролями користувачів та доступами                        |
